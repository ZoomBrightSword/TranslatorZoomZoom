# Kebijakan Privasi

Aplikasi Game Translator ini dirancang dengan privasi Anda sebagai prioritas utama.

## Pengumpulan Data

Aplikasi ini **tidak** mengumpulkan, menyimpan, atau mengirimkan data pribadi apa pun dari komputer Anda. Semua pemrosesan, termasuk pengambilan gambar layar (screen capture) dan pengenalan karakter (OCR), terjadi sepenuhnya secara lokal di mesin Anda.

## Koneksi Jaringan

Secara default, aplikasi ini menggunakan model terjemahan lokal dan **tidak** memerlukan koneksi internet untuk berfungsi.

Jika Anda secara manual mengonfigurasi aplikasi untuk menggunakan backend "api", aplikasi akan mengirimkan teks yang terdeteksi ke server API publik (seperti LibreTranslate) untuk tujuan terjemahan. Permintaan ini tidak menyertakan informasi pribadi atau data identifikasi apa pun tentang Anda atau komputer Anda. Harap tinjau kebijakan privasi dari layanan API yang Anda pilih untuk informasi lebih lanjut.

## Keamanan

Kami tidak mengumpulkan data apa pun, sehingga tidak ada risiko kebocoran data dari pihak kami. Aplikasi ini dirancang agar aman dan menghormati privasi Anda.
